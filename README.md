## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### Use through Laragon on Windows

Laragon's Nginx is configured to proxy `http://portofolio.test` to this Next.js app on port 3000. Start Nginx in Laragon, then run this command from the project folder:

```bash
npm run dev -- --hostname 127.0.0.1
```

Keep the terminal running and open [http://portofolio.test](http://portofolio.test). Stop the development server with `Ctrl+C`. The Laragon proxy configuration is stored in `C:\laragon\etc\nginx\sites-enabled\portofolio.test.conf`.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
